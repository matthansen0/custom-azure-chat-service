# Labs

These labs track the prototype maturity and are designed to stay aligned with `scripts/validate.sh`.

- `01-local-smoke.md`: local Pass 1 validation for the architecture skeleton.
- `02-pass2-working-slice.md`: local validation for the first complete working slice.
- `03-pass3-admin-slice.md`: local validation for the admin, preference, template, directory, context, and audit slice.

Later passes will add deployed Azure walkthroughs and one-to-one live validation coverage.
